# Что посмотреть

Android-приложение: случайный фильм, сериал или аниме из TMDB. Фильтры по жанру, рейтингу и году, список "Посмотрю", скрытие ненужного.

## Запуск

1. Получить токен: themoviedb.org, Настройки, API, "API Read Access Token".
2. В файл `local.properties` в корне проекта добавить строку `TMDB_TOKEN=токен`.
3. Открыть проект в Android Studio, дождаться синхронизации Gradle, запустить.

## Оговорки

- Аниме - это сериалы TMDB с жанром "Анимация" и японским оригинальным языком. Аниме-фильмы идут в разделе "Фильмы".
- Предлагаются тайтлы из первых 20 страниц выдачи по популярности с как минимум 300 голосами.
- Если API недоступен без VPN, потребуется прокси или другой baseUrl в `App.kt`.
- При публикации нужна атрибуция TMDB по их правилам.
